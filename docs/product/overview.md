# AI 能力包产品定位

## 目标

本能力包让支持插件、skills 或 MCP 的 AI 客户端通过统一契约使用华仔 AutoJs 工具箱 V5 的 Android 设备能力，并为 AutoJs 脚本生成和设备操作提供领域规则。

## 使用者

- 使用 AI 观察、操作和验证 Android 设备的开发者与测试人员。
- 生成、提交和排查 AutoJs 脚本的 V5 维护者。
- 需要把 V5 设备能力接入 Codex、Claude Code、ZCode、WorkBuddy 或其他 MCP 客户端的集成人员。

## 能力范围

- 设备发现、状态、截图、布局和日志读取。
- 点击、滑动、输入等受控设备操作。
- AutoJs 脚本提交、任务等待、停止和日志提取。
- 节点、OCR、图像、颜色和页面匹配等识别任务。
- 四项领域 skill：设备操作流程、AutoJs 脚本编写流程、项目开发部署流程与任务探索流程。
- 随包 AutoJs/AutoJsPro 离线文档，及其符号级索引（`autojs_docs_search` / `autojs_docs_read`）。
- 按用途拆分的三个 MCP 通道：设备 MCP 提供设备观察与控制，项目开发 MCP 提供设备文件原语、项目同步、项目运行、打包与 APK 安装，教程录制作者 MCP 提供录制会话、手机端步骤采集、桌面端步骤写入、审核与发布（**默认关闭**，由 `HZ_MCP_ENABLE_TUTORIAL_TOOLS` 或用户级配置开启）。

## 产品边界

- 本项目不实现设备管理、任务调度或商业授权；这些能力属于 V5。
- 本项目不直接通过 ADB 形成正式自动化链路；ADB 只用于开发、安装或救援。
- 本项目不绕过 V5 APP、AutoJs 运行时、无障碍服务或投屏插件。
- 本项目不是通用编码 Agent 平台，也不绑定单一 AI 客户端。

## 分发形态与公开边界

- 面向使用者的完整插件 ZIP 由 V5 与授权中心的「插件包」入口分发，自带编译产物与生产依赖，不需要自行构建；MCP 仍由 Node.js 20+ 运行时启动。
- 面向开发者的源码（本目录与独立源码镜像）不含 `dist` 与 `node_modules`，需要自行安装依赖并构建；两者能力一致，差别只在获取与构建方式。
- 工具箱本体（V5 后端、Android APP、桌面端与授权中心）闭源，本能力包只通过 V5 对外接口工作，不携带本体源码。
- 插件自有源码采用 GPLv3（`GPL-3.0-only`），源码仓库为 `806073526/hz-autojs-ai-capabilities`；许可证见 [LICENSE](../../LICENSE)。

## 安全原则

只读模式、危险动作显式开关、设备锁、V5 访问控制和审计共同约束真实操作。设备访问按设备授权，设备 MCP 与项目 MCP 共享同一授权窗口（教程录制作者 MCP 不访问设备授权，只经 V5 本机作者接口工作）；自动执行开关不能绕过商业授权、设备访问、部署来源边界或审计。客户端能看到工具，不代表拥有越过这些边界的权限。
