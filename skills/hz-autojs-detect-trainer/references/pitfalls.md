# 坑清单（每条都付过学费）

## 环境类

1. **GitHub release 下载慢/超时**（模型权重、AMP 检查权重）。表现：训练卡在下载、速度 <100KB/s。处置：换镜像（`ghproxy.net` / `ghfast.top` / `gh-proxy.com`），或先手工下载 `yolo11n.pt` 放 `<WorkRoot>\models\`。`setup-env.ps1 -GithubMirror` 已内置。
2. **ultralytics 首次运行联网拉资源**：`Arial.ttf`（ultralytics.com，一般可通）与 AMP 检查权重（github.com，易卡）。处置：预置权重文件；或首轮加 `amp=False` 跑通再说。
3. **训练显存被占**：本地大模型服务（如 llama-server）会占用十几 GB 显存，训练直接 OOM。处置：训练前用 `check-env.py` 看空闲显存，占用者先停。
4. **V5 后端必须 JDK 8**：本机 JDK 17/21 下 Tomcat 会"端口在监听但 HTTP 不回包"。处置：用 JDK 8 启动后端（仓库 `startScript/README.md` 有权威说明）。

## 数据类

5. **标注污染**：截图时弹窗可能已自动关闭，得到与背景页相同的图却按"负样本"标注 → 教坏模型。处置：并入前对比近重复图（md5 / 均值哈希）；负样本必须人工看过。
6. **同页不同状态泄漏**：把同一页面的两张截图分别放进 train/val，指标虚高。处置：按页面/状态划分。
7. **颜色规则误伤同色元素**：红字、属性标签、装饰边框会被亮通道命中。处置：封闭白 + 圆形度两道闸；仍不过就整图列显式负样本。
8. **遮罩下的暗目标**：弹窗遮罩会把亮红压成暗红（实测 RGB 可低至 (49,22,23)），单一亮通道规则全漏。处置：暗通道 + 相对亮度。

## 设备与部署类

9. **检测→动作必须同帧**：用几秒前截图的坐标去点击会打偏（画面已变）。正确顺序：截图 → 检测 → 立即点击。
10. **导航类目标的可点区域**：实测斗破底部导航只有**图标区**可点（标签区与整个 item 的中心点都无效）。给区域类目标打标签时，框要覆盖**可点区域**，使框中心=可点坐标；发现点不动先验证可点区域再改标签。
11. **插件模型路径**：`setModel()` 只认设备上的绝对路径，且同目录 `classes.json` 决定类名；类别数与模型输出维度不一致时插件会自动对齐（少补多截），但类名错位会在端上静默出错。
12. **低置信度边缘碎片**：nav 类在屏幕边缘可能出 0.3 左右的碎片框。消费端用 `score >= 0.5` 过滤，不要只靠 conf 阈值——真正的小目标（暗红点）置信度可能低到 0.3，全局抬阈值会漏。
