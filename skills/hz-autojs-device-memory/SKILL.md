# hz-autojs-device-memory

记忆是可选的经验辅助，不是设备任务的启动步骤。稳定、可直接按当前页面执行的任务不得为了“符合流程”先读记忆，也不得因记忆不可用而阻塞正常操作。

## 何时查阅

- 用户明确要求参考历史经验。
- 同一应用、版本和页面上的同一动作重复失败，需要检查已验证绕过或反例。
- 准备复用同一设备、应用版本、页面和执行通道下的已知稳定结论。
- 需要确认旧经验是否因版本、分辨率、模式或素材失效。

普通首次操作和实时证据充分的动作直接执行；记忆不能替代当前观察。

## 查阅顺序

1. 明确 `deviceId` 后，需要时再读 `/sdcard/appSync/memory/index.md`。
2. 按摘要声明的应用、版本、页面、执行模式、通道和素材 ID 匹配，只读相关的 `./<slug>/SKILL.md`。必要条件未知时先核实，未命中不读其他详情。
3. 索引真实不存在才是无经验；拒绝、截断、离线或失败都要如实说明，但不得因此阻塞不依赖记忆的稳定执行。索引截断时停止匹配、读取详情与写入。
4. 路径不可访问时报告工具边界，不把记忆改存到服务器、其他设备或其他目录。

## 验证后保存

出现经证据确认的失败码、失效条件或稳定素材 ID 时，可主动保存最小事实；现有确认门禁照常。同一问题更新原详情，反例只修正适用/失效条件。先写详情并读回，再重读索引合并全部旧条目并写回，最后读回索引；冲突或截断即停止报告。模板与协议见 [references/memory-format.md](references/memory-format.md)，按需展开。

只允许保存：应用、版本、页面、执行模式/通道、素材 ID、适用/失效条件、失败码、证据摘要。禁止保存图片、截图、色组正文、可执行流程、完整节点树、完整日志、账号凭据或页面私密内容。

## 插件文件入口

- `device_file_list`：`deviceId` + `path`，必要时用 `directoriesOnly`、`nameContains` 和分页。
- `device_file_read_text`：先读索引或详情；`truncated=true` 时不得合并覆盖。
- `device_file_operation`：建目录用已核实的 `operation: "MKDIR"`。
- `device_file_write_text`：整文件写入且无哈希前置；写前重读，写后等任务终态并读回。
- 不使用脚本、shell 或泛化任务工具作为文件通道。

## 边界

- `/sdcard/appSync/memory/` 只属于当前目标手机，不自动跨设备或全局共享。
- 稳定执行不得依赖先读记忆；记忆只提供候选条件，动作前必须以当前设备证据复核。
- 不执行记忆中的代码；不存账号、凭据、验证码、聊天内容、个人信息、图片、截图、色组正文、可执行流程、完整日志或节点树。
- 设备访问、文件权限、危险动作确认和商业授权不可绕过。
