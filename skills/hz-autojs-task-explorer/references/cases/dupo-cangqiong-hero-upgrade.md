# 斗破苍穹斗者升级与进阶案例

> 坐标说明：下文绝对坐标是 **1080×1920 基准空间** 的标定值。升级/进阶主按钮、返回箭头都属于贴边元素，移植时应改为 `edge` 模式。

- 类型：资源消耗型养成页
- 入口：底部 `斗者`，坐标 `(261,1877)`
- 目标角色：若琳（首轮）、林修崖（进阶轮）
- 已验证：1→5 级（按钮升级）、5→20 级（长按）、20→40 上限（进阶）

## 状态链

`HERO_LIST` -> `HERO_DETAIL` -> `UPGRADE_RESULT` -> `HERO_DETAIL` -> `ADVANCE_DIALOG` -> `ADVANCE_SUCCESS` -> `HERO_DETAIL` -> `HERO_LIST`

## 关键证据

- 角色卡片位于大约 `(410,550)`。
- 详情页显示 `等级`、`斗气`、`升级X次` 和资源数量。
- `升级4次` 按钮 OCR bounds 为 `(448,1544)-(633,1595)`，中心 `(541,1570)`。
- 使用设备 MCP 在该中心执行一次点击后，若琳从 1 级升到 5 级，斗气与属性同步变化。
- 第二次界面上的按钮文案会变为 `升级5次`，资源消耗数值也变化。

### 长按连续升级（2026-10-01 验证）

- 引导文字 `长按升级可以连续提升等级！` 出现后，改用长按：
  `__toolboxLongPress(540, 1573, 1800)`。
- 一次 1800ms 长按把林修崖从 5 级拉到 20 级（本级上限）。
- 长按比逐次点击更适合作为固化动作；但必须先确认资源足够，否则会在中途停在资源不足状态。

### 斗者进阶（2026-10-01 验证）

- 满级后按钮自动变为 `进阶`，点击弹出 `斗者进阶` 面板。
- 面板内容：`等级上限 20 → 40`、`攻击 377 → 458`（+天赋 350 后实际 758）、`生命 2468 → 2974`、`物防/法防 73 → 88`、`解锁天赋：攻击+350`。
- 消耗：金币 `10000`、专属道具 `50`（面板显示 `40795/10000`、`55/50`）。
- 面板内再点一次 `进阶 (540,1400)` 才真正执行；随后出现 `进阶成功` 展示层，点底部空白区关闭。
- 进阶后详情页显示 `等级 20/40`、`赋 1/8`（天赋槽开启）。

**资源门槛判断：** 面板用 `当前/消耗` 展示，可直接作为是否执行的前置条件；不足时不要点击。

### 斗者经验（升级材料）与获取途径（2026-10-01 晚补录）

- 升级实际消耗两类资源：`斗者经验`（红色经验球）与金币；详情页底部显示 `当前/消耗` 两组数字。
- 经验不足时点击经验图标会弹出 `斗者经验` 说明面板，列出获取途径：`冒险`（推荐）、`修炼收益`（挂机）、`斗气修行`（升至 16 级开启）、`斗技场`。
- 本轮实测经验池耗尽的两次停下：若琳 35/40（经验 `4767/6410`）、范痨 14（经验 `207/1160`）。**长按升级前必须先读 `当前/消耗`**，否则会在中途停下并弹出该说明面板。
- `斗者经验` 面板没有 X 按钮，点面板外空白区即可关闭。
- 进阶材料门槛按品质不同：A 级（若琳）20→40 消耗 50 个专属材料；S+ 级（药老/林修崖）40→50 需要 100 个。材料不足时弹窗内 `当前/消耗` 会以红色显示，按钮不可用。

## 观察

- 第一次升级按钮在 MCP 点击下可靠生效。
- 教学状态下非高亮目标点击会被引导层吞掉；必须跟随引导。
- 退出详情页点金色箭头 `(115,1845)` 可返回列表；点 `(115,1780)` 无效。
- 系统返回键会先弹 `是否退出游戏?`，需要点 `再玩会 (362,1240)`。
- 资源显示为 `当前/消耗` 形式，适合在生成项目中做资源门槛判断。

## 固化建议

1. 用 OCR 识别 `升级X次` 按钮和资源数量。
2. 资源足够时先用单次点击把角色带过教学步骤，再用长按批量升级到上限。
3. 达到上限后识别 `进阶` 按钮，先读进阶面板的 `当前/消耗`，满足才二次确认。
4. 资源不足或按钮消失时停止，不要继续点击空白区域。
5. 每次升级/进阶后重新截图，不能复用旧坐标、旧等级或旧资源值。
