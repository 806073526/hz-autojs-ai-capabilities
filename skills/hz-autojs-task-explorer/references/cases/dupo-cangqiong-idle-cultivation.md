# 斗破苍穹挂机收益案例（修炼石台 / 心火淬炼）

> 坐标说明：下文绝对坐标是 **1080×1920 基准空间** 的标定值。`领取收益` 为贴边元素应用 `edge`，石台入口用 `ratio`，契约见 `assets/coordinate-spec.example.json`。

- 类型：画布 / 自绘型，挂机累积 + 领取型
- 设备：`device_android_e3bf91f528e0bbfe`，1080×1920，竖屏
- 入口：冒险章节地图左下角，`修炼石台` 图标，中心约 `(170,1340)`
- 解锁条件：通关 1-4 后由教程解锁，并弹出 `解锁新功能 - 心火淬炼`
- 证据日期：2026-10-01

## 为什么这是典型的可固化挂机任务

- 状态少、锚点稳定：入口图标 + 倒计时 + `奖励可领取` 标签。
- 反馈明确：`当前积累奖励`、单位时间收益率、可领取数量。
- 可重复：领取后倒计时从 `00:00:00` 重新累积。
- 无支付风险：`领取收益` 只是取回已累积产出。

## 界面结构

```text
IDLE_PLATFORM（修炼石台面板）
  ├─ 标题：购买心火淬炼特权        ← 付费购买入口，探索时不点击
  ├─ 特权解锁进度：通关2-1 / 通关3-8 / 通关5-8
  ├─ 奖励预览：当前积累奖励 + 单位收益率
  ├─ 收益明细：绿 / 红 / 金币 / 卷轴 的当前可领取数量
  ├─ 按钮：快速修炼（立得2小时修炼助力）
  ├─ 按钮：领取收益
  └─ 右上 X 关闭（约 (995,185)）
```

## 单位时间收益率（面板实测）

| 资源 | 收益率 | 说明 |
| --- | --- | --- |
| 绿色 | `54/M` | 每分钟 54 |
| 红色 | `104/M` | 每分钟 104 |
| 金币 | `17/M` | 每分钟 17 |
| 卷轴 | `2.6/M` | 每分钟 2.6 |

面板还提示 `石台额外给你提供了15分钟的修炼收益`，说明除基础累积外还有额外加成。

## 一轮完整操作（已复跑验证）

1. 在冒险章节地图点击 `修炼石台` 图标 `(170,1340)`。
2. 面板打开，OCR / 截图确认 `奖励可领取` 与 `领取收益` 按钮存在。
3. 点击 `领取收益`，坐标约 `(850,1645)`。
4. 弹出 `恭喜获得`：绿色 `810`、红色 `1515`、金币 `255`、卷轴 `38`。
5. 点击任意位置关闭（实测 `(540,1650)`）。
6. 关闭后出现 `等级提升` 弹层（本次升到 5 级），按弹层队列规则逐层关闭。
7. 回到章节地图，`修炼石台` 倒计时重新开始累积：先显示 `00:01:53`，随后增长为 `00:11:15`、`00:17:12`、`00:18:13`。

**可观察的成功判据：**

- 领取前 `当前积累奖励` 显示可领取；领取后重新从零累积。
- 主界面顶栏资源数量在领取后立即增加。

### 教程气泡会吞掉 `领取收益`（2026-10-01 晚补验）

本轮面板是在教程链中途打开的（面板上带教程气泡与 `跳过指引`）。此时点 `领取收益` 返回成功但**不发放奖励**；先点 `跳过指引`（中心约 `(781,850)`）关闭教程层，再点 `领取收益` 才成功，领到 `133 / 26 / 32 / 12947 / 76061 / 1870 / 45`（多类道具）。

- `领取收益` 没有唯一固定位置：两轮实测分别为 `(850,1645)` 与 `(745,1668)`，必须 OCR 定位，不能写死。
- 领取后同样进入 `等级提升`（13 级）与 `解锁新功能`（游历 / 金币修行 / 日常任务 / 试炼之塔 / 斗技场）的弹层队列，逐层点底部 `(540,1695)` 关闭。
- 面板上的付费入口（`购买心火淬炼特权` / `68元激活`）在教程链中也可能被手指指向——那是特权示意图，**不要点击**；需要恢复操作时点 `跳过指引`。

## 与主界面的联动

- 石台图标旁的倒计时直接显示在冒险章节地图上，可作为"是否可以领取"的低成本判断点。
- 领取收益会推动主角色升级，进而触发 `等级提升` 弹层与新的功能解锁，属于挂机收益链的一部分。

## 可固化设计（供生成器编译）

step 1  locate: 在章节地图按模板匹配 修炼石台 图标

step 3  enter:  点击图标进入面板
step 4  guard:  确认面板出现「领取收益」；不要点击「购买心火淬炼特权」

step 6  close:  关闭「恭喜获得」并按弹层队列清屏

参数化建议：按钮坐标、图标模板、倒计时区域全部外置；不要把 `(850,1645)` 写死在业务逻辑里。

可复跑骨架：`assets/probes/dupo-idle-claim.example.js`。

## 风险与边界

- **不要点击** `购买心火淬炼特权` / `快速修炼` 中涉及付费或消耗道具的入口，除非任务明确要求且已确认资源来源。
- `快速修炼` 的 `立得2小时修炼助力` 可能消耗道具，本轮未执行，属于待验证动作。
- 领取频繁时可能触发二次弹层，必须留出关闭弹层的时间。
- 长期挂机需确认收益上限与溢出规则，本轮未验证上限。

## 待验证

- `快速修炼` 是否免费、是否消耗道具、是否有限次。
- 关闭应用后离线时间是否计入收益。
- `境界` 系统是否与挂机收益共用同一套累积机制。
