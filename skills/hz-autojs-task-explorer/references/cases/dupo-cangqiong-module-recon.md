## 侦察方法

- 一级入口是固定布局，可直接用坐标或图色匹配。
- 进入任一模块前先截图确认当前不在全屏遮挡层；遮挡层会吞掉底部导航点击。
- 模块内部按普通画布型处理：截图 + OCR + 图色，节点树不可用。
- 每个模块单独建立状态模型，不要假设六个模块共用同一套子页面。

## 本轮遇到的阻塞

1-3 通关后进入全屏奖励弹层队列，底部导航点击被吞；重启应用恢复主界面后，又遇到教程引导手势层（药老提示 `点击前往"招募"！`），同样会吞掉底部导航点击。实测从城市点击 `历练`，`__toolboxTap` 返回 `success=true` 但页面仍停在城市。

这两次都不是入口坐标错误，而是状态机没有回到可自由操作的主界面：

- 全屏奖励层：按 `dupo-cangqiong-reward-overlay.md` 逐层关闭，点底部空白区避开道具图标。
- 教程引导层：按 `dupo-cangqiong-tutorial-chain.md` 跟随高亮目标推进，直到引导消失。

不要在遮挡层或教程层上连续点击导航，那只会消耗探索预算并掩盖真实阻塞原因。

### 2026-10-01 更新：引导层高亮目标会转移，不是一次消解

跟随教程链（招募 → 冒险 → 关卡 → 布阵 → 战斗 → 挂机领取 → 斗者升级进阶）推进后，引导层**没有整体消失**，而是把高亮目标不断切换到下一步：

```text
城市·招募 → 招募页·免费招募 → 招募页·返回箭头
  → 城市·冒险 → 章节·开始挑战 → 关卡·挑战 → 布阵·换位 → 布阵·出战
  → 奖励弹层队列 → 章节·修炼石台 → 挂机面板·领取收益
  → 城市·斗者 → 斗者列表·林修崖 → 详情·升级 → 详情·进阶
  → 斗者列表·返回 → 城市·冒险 → 1-5 → 弹层 → 城市·任务追踪条
  → 境界面板·领取
```

因此：

- 引导层不是一次性遮挡，而是**逐步转移的输入过滤器**；每一步只有高亮目标可点。
- 引导目标可能不是主模块入口，例如后期的目标是左下角**任务追踪条**（约 `(185,1610)`），点它才打开 `境界` 面板。
- 判断方法：屏幕上出现手指图标 + 提示气泡时，先照做；点击其他入口一律失败，且会浪费探索预算。

## 对照价值

本案例演示了「入口侦察」和「模块内部探索」应当拆成两个阶段：入口是稳定的、可以一次标定；模块内部依赖当前状态是否可操作。混淆这两个阶段会导致在错误状态下反复点击，浪费探索预算。
