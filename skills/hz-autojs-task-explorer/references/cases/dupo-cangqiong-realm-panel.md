# 斗破苍穹境界面板案例（任务领取型）

> 坐标说明：下文绝对坐标是 **1080×1920 基准空间** 的标定值。任务卡的三个 `领取` 按钮应优先用 `anchor`（按任务名 + 按钮文本定位），不要按面板比例推算。

- 类型：画布 / 自绘型，任务条件 + 一键领取
- 设备：`device_android_e3bf91f528e0bbfe`，1080×1920，竖屏
- 解锁：主角色达到 6 级后弹出 `解锁新功能 - 境界`
- 入口：城市页左下角**任务追踪条**，中心约 `(185,1610)`
- 证据日期：2026-10-01

## 入口发现过程（值得复用的一步）

解锁提示 `境界已解锁，去看看吧` 出现后，底部导航被引导层锁住，点 `历练` / `冒险` 均无效。真正可点的是左下角带金色高亮边框的**任务追踪条**（内容为 `奖励：100紫晶卡 / 冒险通关1-7(0/1)`）。

点它才打开 `境界` 面板。**教训：引导目标不一定是模块入口，可能是一个信息条；找不到入口时先找屏幕上唯一带高亮边框的元素。**

## 面板结构

```text
REALM_PANEL
  ├─ 左上：战令（常规奖励 / 进阶奖励）     ← 付费通行证，探索时不点击
  ├─ 中部：斗之气  球体 + 属性加成区
  │        攻击 +0 / 生命 +0 / PVP增伤 +0% / PVP减伤 +0%
  ├─ 境界页签：斗之气 | 斗者 | 斗师 | 大…（按境界等级推进）
  ├─ 任务卡网格（2×2）
  │    招募:获得斗者   在斗者招募召唤1次      进度 1/1   领取 100紫晶卡
  │    斗者:强化升级   1名斗者升至18级        进度 1/1   领取 100紫晶卡
  │    等级提升        等级达到4级            进度 4/4   领取 100紫晶卡
  │    冒险:主线冒险   冒险通关1-7            进度 0/1   前往
  └─ 右下：日常修炼 | 境界（页签切换）
```

## 一轮领取操作（已执行）

1. 点任务追踪条 `(185,1610)` 打开境界面板。
2. 面板提示 `完成境界任务就可以领取一份奖励`。
3. 点第一个 `领取`（`招募:获得斗者`，约 `(400,1355)`）→ 弹出 `恭喜获得 100 紫晶卡`。
4. 点底部空白区 `(540,1650)` 关闭 → 顶栏紫晶卡 `425 → 525`，该任务卡变为 `已完成`。
5. 点第二个 `领取`（`斗者:强化升级`，约 `(880,1355)`）→ 同样 +100 紫晶卡。
6. 关闭后点第三个 `领取`（`等级提升`，约 `(365,1700)`）→ 同样 +100 紫晶卡。

**成功判据：** 任务卡从 `领取` 变为 `已完成`，且顶栏紫晶卡数量按 +100 递增。比只看弹层可靠。

## 任务卡三种状态

| 状态 | 界面表现 | 可执行动作 |
| --- | --- | --- |
| 可领取 | 进度满（如 `1/1`、`4/4`），按钮为 `领取` | 点 `领取` |
| 已领取 | 按钮位置显示 `已完成` | 无 |
| 未达成 | 进度未满（如 `0/1`），按钮为 `前往` | 点 `前往` 跳转目标页 |

## 与挂机体系的关系

`境界` 面板和 `修炼石台（心火淬炼）` 是两套独立系统：

- `修炼石台`：按时间被动累积资源，主动领取。
- `境界`：按任务达成条件领取一次性奖励，并推进 `斗之气 → 斗者 → 斗师 → …` 的境界层级。

两者都属于"条件满足 → 一键领取"的固化模式，共用同一套扫描策略：**遍历面板上的 `领取` 按钮 → 点击 → 关闭奖励弹层 → 复核任务状态与顶栏资源**。

## 可固化设计（组合任务面板）

```text
scan:   截图 + OCR 找出所有「领取」按钮与对应任务名
filter: 只处理按钮文本为「领取」的卡片；跳过「前往」「已完成」
claim:  逐个点击，每次点击后关闭奖励弹层
verify: 复核该卡片状态变化 + 顶栏资源增量
guard:  不点击面板内的战令/购买类入口
```

## 风险与边界

- `战令`（常规奖励 / 进阶奖励）属于付费通行证，探索与固化时都应跳过。
- `前往` 会跳转到其他模块，是否安全取决于目标页；固化时应显式列出允许跳转的目标。
- 任务进度依赖游戏内真实进度，不能靠重复点击刷新。
