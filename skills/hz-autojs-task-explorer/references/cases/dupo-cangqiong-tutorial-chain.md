> 坐标说明：下文绝对坐标是 **1080×1920 基准空间** 的标定值。底部导航、返回箭头、弹层关闭区都属于贴边元素，移植时必须使用 `edge` 模式。

- 类型：画布 / 自绘型，教程引导型 + 连续弹层
- 设备：`device_android_e3bf91f528e0bbfe`，1080×1920，竖屏
- 执行模式：`AUTO`
- 证据日期：2026-10-01

## 一、教程引导层会吞掉非高亮目标的点击

教程期间屏幕上会出现一只手指图标和一段提示文字，例如：

- `点击前往"招募"！`（手指指向城市页的招募入口）
- `强援已加入队伍，再去冒险历练一下吧！`（手指指向底部 `冒险`）
- `点击前往"招募"！` 之后 `点击挑战`、`石台额外给你提供了15分钟的修炼收益，点击进行领取！`

**实测行为：**

- 引导层激活时，点击**非高亮目标**会被吞掉：`__toolboxTap` 返回 `success=true`，但页面不跳转。
- 具体反例：在城市页点击底部 `历练 (783,1877)`，返回成功，但页面仍停在城市。
- 点击**高亮目标**才会被放行：点击 `招募` 成功打开招募页。

**结论：** 引导层不是一个普通弹窗，而是一层输入过滤。探索时若发现"动作成功但状态不变"，先检查屏幕上是否有引导手指；有则必须跟随高亮目标，而不是继续点击自己想去的入口。

## 二、弹层队列：点击可交互图标会制造"关不掉"的假象

通关 1-3 / 1-4 / 1-5 后，结算 `确定` 之后会出现**连续多层**全屏展示，本轮实测队列：

```text
等级提升（数字莲花 + 升级奖励 + 道具图标 + 点击屏幕关闭）
  → 道具详情（紫晶卡 / 拥有数量 / 物品说明）
  → 下一层解锁或奖励提示
  → （队列清空）回到可操作界面
```

**踩坑过程：**

在 `等级提升` 层（标记为 A）里，道具图标位于约 `(540,1490)`；提示文字 `点击屏幕关闭` 位于约 `(540,1670)`。

- 一直点击 `(540,1500)`（正好是道具图标）→ 每次都会**打开**道具详情层 B。
- 点击 B 任意处 → 关闭 B，回到 A。
- 于是画面在 A/B 之间来回切换，看起来像"关不掉"。

**正确定位：**

1. 关闭当前层时，点击**底部提示区或空白区**（约 `(540,1690)`），避开画面中间的道具/按钮图标。
2. 每关闭一层后重新截图确认，不要连续盲点。
3. 队列会依次解锁 `心火淬炼`、`境界` 等新功能提示，全部关完才回到主界面。

**体验教训：** 早期把该现象记录成"非交互遮挡层"，本轮修正为「**可交互弹层队列 + 点击坐标落在可交互图标上导致的循环**」。两者处置不同，必须先验证点击点是否落在可交互元素上，再判定是否非交互。

## 四、动作知识

- **长按**：`__toolboxLongPress(x, y, durationMs)` 可用于"长按连续升级"。实测 1800ms 长按把角色从 5 级拉到 20 级。
- **拖动换位**：`__toolboxSwipe(x1, y1, x2, y2, durationMs)` 可用于角色卡/站位互换。实测 `(160,440) → (375,660)`，900ms 生效。
- **返回箭头**：斗破的圆形金色箭头中心在 `(107,1845)` 附近；不同页面高度略有差异，点 `(115,1845)` 最稳。点 `(115,1780)` 无效。
- **系统返回键**：在游戏内会弹出 `是否退出游戏?` 对话框，需要点 `再玩会 (362,1240)`。

## 五、原生 MCP 与兜底通道

本轮全程使用原生 MCP 工具完成：

- `device_tap`、`device_swipe`（换位）、`device_screenshot`（`includePreview` 直接看图）
- `device_run_script_text`（长按、批量点击、日志 marker）
- 本记录形成时还使用 `device_find_text`、`device_ocr` 做文本锚点与坐标校正；这些旧入口已退役。当前源码使用 `device_tap_target` 的 `TAP_TEXT` 做 OCR 点击，并且必须先确认点击副作用。

插件兜底调用器 `mcp-call.mjs` 只在原生工具未注册或缺失时使用。两者走同一套 V5 授权与风险判定。
