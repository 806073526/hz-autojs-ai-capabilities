## 已观察事实

- 游戏入口和战斗流程可以完整走通，战斗存在自动结算。
- 第一次挑战后解锁升级展示，角色从 1 级升到 5 级。
- 升级会同时改变斗气、生命、攻击和防御等可观察数值。
- 跳过剧情后角色已存在，可进入主城。
- 系统返回键会弹出退出游戏确认框，必须恢复为 `再玩会`。
- 教学引导手势会覆盖目标按钮区域，纯按坐标点击可能无效。
- 战斗动画期间 `device_screenshot` 带 `waitStable` 可能超时；不带稳定等待的截图仍可用。
- 截至 2026-09-30，1-1、1-2、1-3 已通关；1-4 已解锁但未挑战。
- 截至 2026-10-01，1-1 至 1-5 已通关，1-6 / 1-7 待解锁推进。
- 主角色等级 6，紫晶卡 425，金币 44795（1-5 通关后）。
- 已解锁系统：`心火淬炼`（修炼石台挂机收益）、`境界`。
- 林修崖：等级 20/40，斗气 6970，攻击 758，生命 2974，双防 88，已进阶并解锁天赋「攻击+350」。
- 1-3 通关后角色升到 3 级，结算奖励为紫晶卡 / 绿 / 红 / 金币。
- 结算后的 `等级提升` + 道具说明是非交互遮挡层：连续点击返回 `success=true` 但画面锚点不变，详见遮挡层案例。

## 首个可固化目标

推荐先固化 `斗者升级`：

- 状态单一，按钮位置稳定。
- 反馈明确，等级、属性和资源数量变化可见。
- 无支付风险，只消耗游戏内常规资源。
- 需要条件判断：资源不足时停止；教学遮挡时先清理引导。

次选是 `冒险挑战 1-N`：

- 流程包含章节列表、布阵、战斗、结算和奖励展示。
- 状态更多，但可重复，适合作为生成项目的多状态样本。
- 需要处理升级展示和奖励弹层。

## 待验证假设

- 升级按钮在非教学状态下能否连续点击并稳定升级。
- 资源不足时按钮的失败反馈和可恢复状态。
- 不同章节和不同分辨率下坐标是否稳定。
- 长时间挂机是否存在自动战斗、自动拾取或体力限制。
